# docs

本目录存储项目开发过程产生的所有文档，包含项目治理、设计、开发日志。以目录结构约束文档结构。

## 目录结构

- `概念设计.docx` — 项目最高层概念约束，包含项目整体、业务功能、定位与开发策略
- `agents/` — 按工作流程组织的 Agent 记忆与规范

## 目录规范

### agents/

- 存放开发过程中 Agent 的记忆与规范文档
- 文件名格式：`序号.标题-进行时/已完成`，序号自 1 起序列生成
- 文档内容：所属阶段与工作流程 + 会话工作规范 + 记忆整理（仅保留下次零上下文重启工作流程所需记忆，不含已完成工作的存档记忆）
- 工作流程完成后，对应文档状态后缀由"进行时"改为"已完成"
